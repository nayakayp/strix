---
title: "Coding Agents"
description: "Run local Natsuhat scans from AI coding agents"
---

Natsuhat's consumer skills are in the repository's `skills/` directory. Start with
`penetration-testing-with-natsuhat` for setup, then use the application, API, web,
code-review, OWASP, remediation, or CI workflow that matches the task.

Run from this checkout with `uv run --frozen natsuhat`. Agents should always pass
`-n` for headless operation and set `--max-budget` unless instructed otherwise.
Docker and a configured model provider are required. Build the sandbox with
`bash scripts/docker.sh local` before the first scan.

There is no managed-platform fallback, hosted sign-in, billing flow, or source
upload service. Only test authorized targets. Store provider credentials securely.

Every run writes machine-readable findings and SARIF under
`natsuhat_runs/<run-name>/`. Check `run.json` status, scope, and budget before
calling a result clean. See the repository's `AGENTS.md` for development guidance.
