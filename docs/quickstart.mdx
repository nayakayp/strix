## Prerequisites

- Docker (running)
- An LLM API key from any [supported provider](/llm-providers/overview) (OpenAI, Anthropic, Google, etc.)

## Installation

From the repository checkout:

```bash
uv tool install .
bash scripts/docker.sh local
```

## Configuration

Set your LLM provider. We recommend GLM-5.3 through [Vercel AI Gateway](/llm-providers/vercel-ai-gateway) or [OpenRouter](/llm-providers/openrouter):

<CodeGroup>
```bash Vercel AI Gateway
export NATSUHAT_LLM="vercel_ai_gateway/zai/glm-5.3"
export LLM_API_KEY="your-api-key"
```

```bash OpenRouter
export NATSUHAT_LLM="openrouter/z-ai/glm-5.3"
export LLM_API_KEY="your-api-key"
```
</CodeGroup>

<Tip>
For best results, use `zai/glm-5.3`, `deepseek/deepseek-v4.1-flash-1017`, `anthropic/claude-opus-5-5` (needs [CVP](https://support.claude.com/en/articles/14604842-cyber-verification-program) access), or `openai/gpt-6.1-sol` (needs [Daybreak](https://openai.com/daybreak/) access).
</Tip>

## Run Your First Scan

```bash
natsuhat --target ./your-app
```

<Note>
Build the Docker sandbox image locally before the first scan. Results are saved to `natsuhat_runs/<run-name>`.
</Note>

## Target Types

Natsuhat accepts multiple target types:

```bash
# Local codebase
natsuhat --target ./app-directory

# GitHub repository
natsuhat --target https://github.com/org/repo

# Live web application
natsuhat --target https://your-app.com

# Multiple targets (white-box testing)
natsuhat -t https://github.com/org/repo -t https://your-app.com

# Targets from a file, one target per non-empty, non-comment line
natsuhat --target-list ./targets.txt
```
